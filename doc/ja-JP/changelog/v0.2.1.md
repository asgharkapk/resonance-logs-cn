# Changelog v0.2.1

## 更新内容

### DPS / 履歴

- 戦闘パイプラインを再構築：履歴を詳細セグメントとして保存し、任意のタイムライン参照に対応

  ![履歴タイムライン](../../shared/img/changelog/v0.2.1_2.png)

- Live タイマーをバックエンド計時に直接接続

### リアルタイムモニター

- カスタムカウンターの因子エリアを S4 ノード Buff 効果に対応し、自動で監視・表示

  ![S4 ノード Buff 因子エリア](../../shared/img/changelog/v0.2.1_1.png)

- 炎角計算に狂音スキルを追加

### 音声読み上げ

- 中国語 / 英語 / 日本語のプリセット音声デフォルト選択を追加（画面言語に応じて自動選択）
- 微調整モデルの検証結果を永続化し、起動時の再計算を回避

### ロードアウト

- 欠損フィールドがある場合でも古いバージョンのロードアウトをインポートできるよう修正

### 安定性

- ゲーム内で Alt を押してマウスを出した後、閉じる / 最小化をクリックするとアプリ全体が応答しなくなる問題を修正。`WM_NCLBUTTONDOWN` をインターセプトし、カーネルの入れ子追跡ループを回避
- `monitorRuntime` の同時読み書きにより設定が不完全に読み込まれる可能性があった問題を修正

## 注意事項

### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.1 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.1 はバックエンドパイプラインを再構築しています。既存機能に問題があれば速やかにご連絡ください
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
